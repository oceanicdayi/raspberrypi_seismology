# raspberrypi_seismology

這是一份以 **繁體中文** 撰寫的樹莓派實作筆記，整理了樹莓派在硬體通訊與感測器應用上的常見操作與排錯流程。

目前專案主要內容位於 `/home/runner/work/raspberrypi_seismology/raspberrypi_seismology/index.html`，可直接用瀏覽器開啟閱讀。

## 專案內容

本專案涵蓋以下主題：

- USB-to-TTL 6 色線與 Raspberry Pi UART 接線方式
- Windows 下 PL2303 / 序列埠驅動問題排除
- MobaXterm 序列埠連線設定
- 樹莓派掉壓（Undervoltage）警告處理
- 終端機下的 Wi-Fi 設定與故障排查
- MPU6050 加速度計 / 陀螺儀的接線與 Python 讀值範例

## 使用方式

1. 下載或複製此專案。
2. 直接用瀏覽器開啟 `index.html`。
3. 依照頁面中的章節說明進行接線、設定與測試。
